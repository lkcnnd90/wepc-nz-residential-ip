## 「三网绕美」意味着什么，中转这笔钱该不该花

新西兰离国内本来就远，官方的路由选择是三家运营商回程都经由美国。地理距离加上绕行，国内直连的延迟不会占优势，第三方的测评记录也印证了这一点：海外方向能跑满 100Mbps，国内单线程上传多在 10–20Mbps 区间，延迟偏高。

发视频不受影响，一次上传几分钟的事。直播就不一样了，推流对丢包和抖动敏感，延迟高会表现为画面卡、掉线、观众端缓冲。官方在产品页直接写了「直播建议中转」，这句话比任何形容词都有用。

官方中转产品 AUD$29.90/月，给 500GB 流量和 3 个中转，分两条线路：深港 IEPL 按 4 倍率计费，电信用户建议走；海外优化线路按 2 倍率，移动用户建议走。**联通用户用不了这个官方中转**，这是硬限制，不是建议。

所以做新西兰区直播的真实月成本是 19.90 + 29.90 = **AUD$49.80**，前排很多文章只报 AUD$19.90，把这笔账省掉了。加上中转之后，成本已经接近日本那个 AUD$49.90 的「直播无需中转」套餐，选之前值得先想清楚你的目标市场到底是新西兰还是日本。

## 常见问题

**新西兰家宽和澳洲家宽能混用吗？**
不能。IP 归属国不同，TikTok 判定账号所在市场用的是 IP 地理位置，澳洲 IP 做不了新西兰本地流量。同一批账号最好统一在一个国家，避免画像混乱。

**九折码能和年付八折叠加吗？**
没有任何来源说明这两个码可以叠加，官方页面也没有相关规则。结算页输入后显示什么价就是什么价，别按叠加后的数字做预算。

**2TB 双向流量够直播吗？**
上下行合并计量。以 100Mbps 带宽满跑，一小时双向合计的理论上限在几十 GB 量级，实际推流码率远低于带宽峰值，正常直播一个月 2TB 通常够用，但长时间高码率推流要自己盯流量。

**退款期内怎么把流量控制在 10GB？**
先查 IP，再测一次短时推流，别一上来就跑长时间高清直播。测完立刻做决定，拖到第 4 天就只能按每天 6% 折损退余额了。
